How to install this add-in
1
Open Outlook desktop. Click File → Manage Add-ins (or Get Add-ins in the ribbon). This opens the add-in store in your browser.
2
Click My add-ins in the left sidebar, then scroll down and click Add a custom add-in → Add from file…
3
Select the manifest.xml file from the downloaded zip. Click Install when prompted.
4
Restart Outlook. Open any email — you'll see Inbox Automation in the ribbon. Click it to open this panel.
ℹFor organization-wide deployment, an IT admin can deploy via the Microsoft 365 Admin Center → Settings → Integrated apps.
